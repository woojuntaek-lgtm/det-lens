# 행렬식 돋보기

77년이 0.02초로 — 행렬식이 무엇을 재고, 어떤 성질 덕분에 빨리 구할 수 있는지 손으로 체험하는 앱입니다. 3×3 여인수 전개 단계 실행과 n! 항의 폭발, 행 바꾸기·곱하기·더하기·전치·소거의 효과, 넓이·부피의 배율과 음수 행렬식(뒤집힘), 행렬식이 0인 선형 종속과 다중 공선성(키 cm·m), 0에 가까운 병약한 행렬과 조건수까지 담았습니다. 선형대수 04 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 전개: 숫자를 바꿀 수 있는 3×3 행렬, 부호판, 전개할 줄 고르기, 소행렬식·여인수 단계 실행, n! vs n³/3 계산량 비교
- ② 성질: 행 교환·한 행 k배·행 더하기·전체 2배·전치·소거로 삼각 행렬 실험실, 퀴즈 ①, det(AB)와 det(A⁻¹) 확인
- ③ 넓이: 2×2 슬라이더로 정사각형 → 평행사변형, 넓이 배율과 거울 뒤집힘, 퀴즈 ②, 차원별 k^n 배율 표
- ④ 0 근처: 선형 종속 예시, 키(cm)+키(m)의 XᵀX 행렬식, 거의 평행한 두 직선과 조건수, 세 줄 정리, 생각해 볼 질문
